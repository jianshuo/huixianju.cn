## 工作流程
业委会应该遵循提议制度。通过微信群或者业主接待日等方式接受业主建议，并且形成书面动议。

业委会会议就具体的动议进行讨论。

0 需要跟进的，进行回复，并且指定小区相应工作小组的责任人解决。
0 需要表决的，根据议事规则表决。所有业委会成员需要向全体业主公布投票内容，同时可以公布投票选择原因
0 需要提交业主大会的，提交下一次业主大会会议表决。

## 业委会构成
0 在适当的时间，提交业主大会会议增加至7人。

## 业委会下属工作小组的构成
业委会具体的工作，应该成立专门的工作小组，邀请业主参与。初步的工作小组包括：

0 物业管理公司监督指导小组
0 物业管理公司预算管理小组
0 项目招标工作小组（电梯招标小组，建设招标小组）
0 物业公司选聘小组
0 绿化监督指导小组
0 信息技术工作小组

等等。每个小组应该有3-9名工作人员不等，应该是该领域的专业能力，拥有明确的权力，对于最终的结果向业主大会负责。
